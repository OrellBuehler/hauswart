Support

Deutsch

hauswart is an open project run in spare time. Help is given through the project's issue tracker on GitHub.

Getting help

  • A problem or a question: open an issue at github.com/OrellBuehler/hauswart/issues. Say which app (iPhone, Android or web) and which versions of the app and the server you use; both are shown in the app under More, Settings.
  • A security problem: please do not open a public issue. Use "Report a vulnerability" on the Security page of the repository.
  • Setting up a server: the README describes how to run hauswart with Docker and how to connect Home Assistant, Paperless-ngx and a finance app.

Before you write

  • The app needs a server. hauswart is self-hosted: the app is a client for a hauswart server you or someone in your household runs. Without one there is nothing to sign in to.
  • "The server is not reachable": open the same address in the phone's browser. If the web app does not load there either, the phone cannot reach the server (not on the home network, VPN off, wrong port). hauswart must be served at the root of its host, not under a path.
  • "No account has been set up yet": finish the first-run setup in the browser, then sign in in the app.
  • Signed out after about three months: a device stays signed in for 90 days. The app tells you two weeks before; sign in again with your password.
  • No reminders: allow notifications for hauswart in the phone's settings and switch reminders on in the app under More, Settings. Reminders are planned on the phone whenever the app can reach your server, so open the app from time to time when you are away from the home network for long.
  • Something is missing in the app: changing the password, API tokens, user management, calendar feeds and guest links are done in the web app.

Removing your data

Sign out in the app (More, Settings) to remove the device token and planned reminders from the phone, or delete the app. The token can also be revoked in the web app under Settings, Devices. Your household's data is on your server; the developer has no copy. See the privacy policy.

Hilfe

hauswart ist ein offenes Projekt, das in der Freizeit entsteht. Hilfe gibt es über die Issues des Projekts auf GitHub.

Hilfe bekommen

  • Ein Problem oder eine Frage: eröffne ein Issue auf github.com/OrellBuehler/hauswart/issues. Gib an, welche App (iPhone, Android oder Web) und welche Versionen von App und Server du nutzt; beide stehen in der App unter Mehr, Einstellungen.
  • Ein Sicherheitsproblem: bitte kein öffentliches Issue. Nutze «Report a vulnerability» auf der Security-Seite des Repositorys.
  • Einen Server einrichten: das README beschreibt, wie hauswart mit Docker läuft und wie Home Assistant, Paperless-ngx und eine Finanz-App angebunden werden.

Bevor du schreibst

  • Die App braucht einen Server. hauswart wird selbst gehostet: Die App ist ein Client für einen hauswart-Server, den du oder jemand in deinem Haushalt betreibt. Ohne Server gibt es nichts, woran man sich anmelden könnte.
  • «Der Server ist nicht erreichbar»: öffne dieselbe Adresse im Browser des Telefons. Lädt die Web-App dort auch nicht, erreicht das Telefon den Server nicht (nicht im Heimnetz, VPN aus, falscher Port). hauswart muss direkt unter dem Hostnamen laufen, nicht unter einem Pfad.
  • «Auf diesem Server ist noch kein Konto eingerichtet»: schliesse die Einrichtung im Browser ab und melde dich dann in der App an.
  • Nach rund drei Monaten abgemeldet: ein Gerät bleibt 90 Tage angemeldet. Die App weist zwei Wochen vorher darauf hin; melde dich mit deinem Passwort neu an.
  • Keine Erinnerungen: erlaube Mitteilungen für hauswart in den Einstellungen des Telefons und schalte Erinnerungen in der App unter Mehr, Einstellungen ein. Erinnerungen werden auf dem Telefon geplant, sobald die App deinen Server erreicht; öffne die App also ab und zu, wenn du länger nicht im Heimnetz bist.
  • Etwas fehlt in der App: Passwort ändern, API-Tokens, Benutzerverwaltung, Kalender-Feeds und Gästelinks gibt es in der Web-App.

Deine Daten entfernen

Melde dich in der App ab (Mehr, Einstellungen), um das Geräte-Token und die geplanten Erinnerungen vom Telefon zu entfernen, oder lösche die App. Das Token lässt sich auch in der Web-App unter Einstellungen, Geräte widerrufen. Die Daten eures Haushalts liegen auf eurem Server; der Entwickler hat keine Kopie. Siehe die Datenschutzerklärung.
